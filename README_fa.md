# Audio8-Persian-TTS 🎙️🇮🇷

**فاین‌تیون مدل [Audio8 TTS](https://github.com/Edge0-AI/Audio8_TTS) برای زبان فارسی.** Audio8 یک مدل چندزبانه‌ی تبدیل متن به گفتار با ۰.۶ میلیارد پارامتر و قابلیت کلون صداست که به‌طور رسمی از فارسی پشتیبانی نمی‌کند.

تا جایی که می‌دانیم (بررسی‌شده در مهر ۱۴۰۵)، این **اولین نسخه‌ی عمومی فارسیِ Audio8 TTS** است و با سخت‌افزار رایگان یا کم‌هزینه‌ی Google Colab آموزش دیده است.

## 📊 نتایج (نسخه‌ی ۰.۲)

| | مقدار |
|---|---|
| داده‌ی آموزش | ۳۳ بخش از ۷۷ بخش Mana-TTS + کل GPTInformal: **۳۱٫۶ ساعت صدا** بعد از فیلتر کیفیت |
| تعداد قدم / epoch | ۷۰۰۰ / ۲ |
| GPU | یک T4 در Colab، در چند جلسه که هر بار از چک‌پوینت روی Hugging Face ادامه پیدا کرد |
| eval loss | ۸٫۰۰ در قدم ۷۰۰۰ (نسخه‌ی ۰.۱: ۸٫۸۰؛ مجموعه‌ی ارزیابی دو نسخه یکی نیست) |
| کیفیت شنیداری | گفتار فارسی قابل فهم؛ لحن هنوز کمی رباتیک است |
| CER (تبدیل صدای تولیدشده به متن با Whisper) | هنوز اندازه‌گیری نشده |
| MOS (نمره‌ی شنوندگان فارسی‌زبان) | هنوز اندازه‌گیری نشده |

## 🚀 شروع سریع

1. روی دکمه‌ی **Open in Colab** بزنید.
2. از منوی **Runtime → Change runtime type** یک GPU انتخاب کنید (L4 یا A100 پیشنهاد می‌شود؛ T4 رایگان کندتر است).
3. یک توکن **write** در Hugging Face بسازید و در پنل 🔑 Secrets در Colab با نام `HF_TOKEN` ذخیره کنید.
4. سلول تنظیمات را نگاه کنید (`HF_USERNAME`) و **Runtime → Run all** را بزنید.
5. اگر جلسه تمام شد، دوباره **Run all** بزنید، روی همان سیستم یا هر سیستم دیگر (Colab یا Kaggle). داده و چک‌پوینت‌ها روی Hugging Face ذخیره شده‌اند و آموزش ادامه پیدا می‌کند.

## 🔧 روش کار

- **داده فقط یک بار آماده می‌شود:** هر بخش دیتاست دانلود، به کدهای کدک Audio8 تبدیل و روی Hugging Face ذخیره می‌شود (کل ۱۱۴ ساعت Mana کمتر از ۳۰۰ مگابایت).
- **چک‌پوینت‌ها روی یک مخزن خصوصی Hugging Face:** فقط جدیدترین نگه داشته می‌شود و از هر سیستمی می‌شود آموزش را ادامه داد.
- **کلون صدا به فارسی:** داده‌ی Mana بیشتر بدون صدای مرجع آموزش می‌بیند (صدای پیش‌فرض مدل، گوینده‌ی Mana است). داده‌ی GPTInformal همیشه با یک صدای مرجع از همان گوینده آموزش می‌بیند تا مدل کلون صدا را به فارسی یاد بگیرد.
- **مقاوم در برابر قطعی Colab:** چک‌پوینت‌های ناقص تشخیص داده و کنار گذاشته می‌شوند.
- **رفع مشکلات اسکریپت اصلی:** فایل DeepSpeed موجود نیست، gradient checkpointing در مدل پیاده نشده، loss در gradient accumulation نرمال نمی‌شود و وزن‌ها با bf16 خالص آموزش می‌بینند. جزئیات در [README انگلیسی](README.md#fixes-to-the-upstream-sft-pipeline).

## ⚠️ محدودیت‌ها

- **داده:** نسخه‌ی ۰.۲ از ۳۱٫۶ ساعت صدا (۳۳ بخش از ۷۷ بخش Mana-TTS + GPTInformal) استفاده می‌کند. Mana-TTS عملاً **یک گوینده** است و GPTInformal گوینده‌ی دوم را اضافه می‌کند. لحن هنوز کمی رباتیک است. تنوع لحن و صدا محدود است و کلون صدای افراد ناآشنا ضعیف‌تر از زبان‌های اصلی Audio8 است.
- **سخت‌افزار:** یک T4 در Colab (۷۰۰۰ قدم، ۲ epoch). آموزش طولانی‌تر و جست‌وجوی هایپرپارامتر با این بودجه ممکن نبود.
- **بدون تبدیل نویسه به واج (G2P):** خط فارسی مصوت‌های کوتاه را نمی‌نویسد، پس مدل تلفظ را از داده یاد می‌گیرد. کلمات هم‌نویسه (مثل کُرد / کَرد)، کسره‌ی اضافه و کلمات نادر ممکن است اشتباه خوانده شوند.
- **پوشش متن:** اعداد به حروف تبدیل می‌شوند، ولی تاریخ، اختصارها و کلمات انگلیسی وسط متن به‌طور خاص پردازش نمی‌شوند.
- **مدل پایه:** Audio8 نسخه‌ی Preview است و فارسی در پیش‌آموزش آن نبوده.
- **ارزیابی:** هنوز ارزیابی انسانی (MOS) و سنجش خودکار قابل‌فهم بودن (CER) انجام نشده؛ قضاوت کیفیت فقط با گوش دادن است.

## 🟢 کردی سورانی

یک نوت‌بوک جدا برای کردی سورانی هم هست: [`notebooks/Audio8_Kurdish_Sorani_Finetune.ipynb`](notebooks/Audio8_Kurdish_Sorani_Finetune.ipynb). داده‌اش [central-kurdish-tts4all](https://huggingface.co/datasets/aranemini/central-kurdish-tts4all) است: حدود ۳۵ ساعت گفتار خوانده‌شده از ۳ گوینده.

- **نقطه‌ی شروع:** با `INIT_MODEL = "persian"` آموزش از مدل فارسی شروع می‌شود، چون خط سورانی و فارسی خیلی شبیه‌اند. با `"base"` از Audio8 اصلی شروع می‌شود. برای مقایسه، برای هر کدام `RUN_NAME` جدا بگذارید.
- **متن:** تابع `normalize_ckb` حروف سورانی (ە ڕ ڵ ۆ ێ ڤ) را نگه می‌دارد و اعداد را به کردی می‌نویسد.
