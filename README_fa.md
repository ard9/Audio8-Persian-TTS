# Audio8-Persian-TTS 🎙️🇮🇷

**فاین‌تیون مدل [Audio8 TTS](https://github.com/Edge0-AI/Audio8_TTS) برای زبان فارسی.** Audio8 یک مدل چندزبانه‌ی تبدیل متن به گفتار با ۰.۶ میلیارد پارامتر و قابلیت کلون صداست که به‌طور رسمی از فارسی پشتیبانی نمی‌کند.

تا جایی که می‌دانیم (بررسی‌شده در مهر ۱۴۰۵)، این **اولین نسخه‌ی عمومی فارسیِ Audio8 TTS** است و با سخت‌افزار رایگان یا کم‌هزینه‌ی Google Colab آموزش دیده است.

[![Model on HF](https://img.shields.io/badge/%F0%9F%A4%97%20Model-Audio8--TTS--Persian-yellow)](https://huggingface.co/ArminRahimi/Audio8-TTS-Persian)

## 📊 نتایج

| | مقدار |
|---|---|
| داده‌ی آموزش | ۱۰ بخش از ۷۷ بخش Mana-TTS (حدود ۱۵ ساعت) + کل GPTInformal (حدود ۶ ساعت) |
| تعداد قدم / epoch | ۱۲۵۷ / ۳ |
| GPU و زمان آموزش | یک TODO GPU در Colab، حدود ۲.۲ ساعت |
| eval loss | ۹٫۰۰ (قدم ۳۰۰) → ۸٫۸۰ (قدم ۱۲۰۰) |
| CER (تبدیل صدای تولیدشده به متن با Whisper) | هنوز اندازه‌گیری نشده |
| MOS (نمره‌ی شنوندگان فارسی‌زبان) | هنوز اندازه‌گیری نشده |

## 🚀 شروع سریع

1. روی دکمه‌ی **Open in Colab** بزنید.
2. از منوی **Runtime → Change runtime type** یک GPU انتخاب کنید (L4 یا A100 پیشنهاد می‌شود؛ T4 رایگان کندتر است).
3. سلول تنظیمات را نگاه کنید و **Runtime → Run all** را بزنید.
4. اگر Colab قطع شد، دوباره **Run all** بزنید. داده، چک‌پوینت‌ها و نمونه‌صداها در Google Drive شما ذخیره شده‌اند و آموزش از آخرین چک‌پوینت ادامه پیدا می‌کند.

## 🔧 روش کار

- **داده فقط یک بار آماده می‌شود:** هر بخش دیتاست دانلود، به کدهای کدک Audio8 تبدیل و در Drive ذخیره می‌شود (کل ۱۱۴ ساعت Mana کمتر از ۵۰۰ مگابایت).
- **کلون صدا به فارسی:** داده‌ی Mana بیشتر بدون صدای مرجع آموزش می‌بیند (صدای پیش‌فرض مدل، گوینده‌ی Mana است). داده‌ی GPTInformal همیشه با یک صدای مرجع از همان گوینده آموزش می‌بیند تا مدل کلون صدا را به فارسی یاد بگیرد.
- **مقاوم در برابر قطعی Colab:** چک‌پوینت‌های ناقص تشخیص داده و کنار گذاشته می‌شوند و چک‌پوینت‌های قدیمی از سطل زباله‌ی Drive هم پاک می‌شوند.
- **رفع مشکلات اسکریپت اصلی:** فایل DeepSpeed موجود نیست، gradient checkpointing در مدل پیاده نشده، loss در gradient accumulation نرمال نمی‌شود و وزن‌ها با bf16 خالص آموزش می‌بینند. جزئیات در [README انگلیسی](README.md#fixes-to-the-upstream-sft-pipeline).

## ⚠️ محدودیت‌ها

- **داده:** نسخه‌ی ۰.۱ فقط ۱۰ بخش از ۷۷ بخش Mana-TTS (حدود ۱۵ ساعت)، عملاً از **یک گوینده**، و حدود ۶ ساعت از گوینده‌ی دوم. تنوع لحن و صدا محدود است و کلون صدای افراد ناآشنا ضعیف‌تر از زبان‌های اصلی Audio8 است.
- **سخت‌افزار:** یک GPU در Colab به مدت حدود ۲.۲ ساعت (۱۲۵۷ قدم). داده‌ی بیشتر، آموزش طولانی‌تر و جست‌وجوی هایپرپارامتر با این بودجه ممکن نبود.
- **بدون تبدیل نویسه به واج (G2P):** خط فارسی مصوت‌های کوتاه را نمی‌نویسد، پس مدل تلفظ را از داده یاد می‌گیرد. کلمات هم‌نویسه (مثل کُرد / کَرد)، کسره‌ی اضافه و کلمات نادر ممکن است اشتباه خوانده شوند.
- **پوشش متن:** اعداد به حروف تبدیل می‌شوند، ولی تاریخ، اختصارها و کلمات انگلیسی وسط متن به‌طور خاص پردازش نمی‌شوند.
- **مدل پایه:** Audio8 نسخه‌ی Preview است و فارسی در پیش‌آموزش آن نبوده.
- **ارزیابی:** هنوز ارزیابی انسانی (MOS) و سنجش خودکار قابل‌فهم بودن (CER) انجام نشده؛ قضاوت کیفیت فقط با گوش دادن است.
